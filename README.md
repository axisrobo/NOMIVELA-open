# NOMIVELA Open

Public distribution repository for NOMIVELA.

## Contents

- Product website and public documentation
- Go SDK and integration examples
- Public API specifications
- Redistributable NOMIVELA Core binary releases

This repository must not contain NOMIVELA Core source code, Enterprise Edition code, internal design documents, or credentials.

The current public operational API is described in `contracts/core-api.openapi.yaml`.
