# Agent Guidance

Use Superpowers as the development harness. Keep this repository limited to public assets, contracts, SDKs, examples, and distributable Core binaries.

## Version Management

- Every release uses `major.minor.patch` (for example `0.1.0`, `1.4.2`). No pre-release or build suffixes.
- Open and Core (`NOMIVELA`) always share the same version number and the same tag `v<major>.<minor>.<patch>`, each tagged at its own repository commit.
- EE (`NOMIVELA-ee`) has an independent version and independent tag; alignment with this repository is not required.
- The authoritative rule is the Core skill `.superpowers/skills/nomivela-release-versioning/SKILL.md`.
- Push tags only with explicit user confirmation.
